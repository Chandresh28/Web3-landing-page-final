# Web3 | The Next Layer

A beginner-friendly Web3 landing page built to explain the basics of decentralized technology through simple explanations, interactive visuals, and familiar real-world examples.

I created this project as a way to explore Web3 concepts while also experimenting with HTML, CSS, and JavaScript to build a responsive and interactive website.

## What the Website Covers

The website starts with the evolution from Web 1.0 to Web 2.0 and Web3, then breaks down some of the main ideas behind Web3.

It covers:

- Blockchain
- Decentralization
- Smart Contracts
- NFTs
- Cryptocurrency
- DAOs

It also includes a simplified interactive flow showing how a Web3 interaction can involve the user, a wallet, a blockchain, and a smart contract.

## Web3 in Real Life

The website also uses familiar examples to make the concepts easier to understand:

- **Gaming:** A comparison between traditional in-game assets and the idea of blockchain-recorded digital ownership.
- **Social Media:** How decentralized social networks could explore portable digital identity across compatible applications.
- **Finance:** How cryptocurrency can allow value to move between digital wallets on blockchain networks.
- **Digital Ownership:** How NFTs can represent unique digital assets or memberships with ownership associated with a blockchain record.

These examples are used to explain Web3 concepts and do not imply that the referenced Web2 platforms are themselves Web3 applications.
